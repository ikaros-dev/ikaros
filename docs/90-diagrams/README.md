# 图表展示

本目录专门存放从各类 Markdown 文档中整理出的图表、流程图、架构图和领域关系图。

## 目录约定

- 每个图表使用一个独立的 `.md` 文件维护。
- 图表优先使用 Mermaid，便于在 GitHub、编辑器和文档站点中直接渲染。
- 文件名使用 `主题-图表类型.md`，例如 `resource-storage-flow.md`。
- 每个图表文件应注明来源文档，并链接回对应章节。
- 本目录只负责展示和索引，不替代阶段目录中的产品或设计正文。
