# 个人中心与 Console 偏好交互规格

> 本目录描述当前登录用户自己的资料、地区与时间、外观、Console 使用偏好、个人通知和个人安全入口。它通过 Top App Bar 的头像菜单进入，不作为左侧业务子系统菜单分组。

## 1. 头像菜单

头像菜单固定结构：

1. 顶部当前用户摘要：头像、显示名称、用户名/主登录标识安全摘要。
2. `个人资料`。
3. `偏好设置`。
4. `通知设置`。
5. `安全与认证`。
6. 分隔线。
7. 主题快捷切换。
8. 语言快捷切换。
9. `退出登录`。

交互规则：
- 点击用户摘要进入 `/console/account/profile`。
- 主题/语言快捷切换立即生效，并同步到偏好；保存失败时回滚并提示。
- `安全与认证` 对普通用户进入自己的安全页面；具有管理权限的用户仍可通过“身份与安全”管理其他用户。
- `退出登录` 在当前存在未保存普通编辑内容时先提示；Secure Domain 未保存内容按对应保险库规则处理。
- 普通退出只清除当前浏览器本地 JWT / Credential Cache，不调用“撤销当前会话”接口。

## 2. 个人资料

**路由：** `/console/account/profile`

### 页面标题区

- H1 `个人资料`。
- 副标题 `管理你的显示信息与个人账号资料。`
- 默认不放置危险账号操作。

### 资料卡

字段：
- 头像。
- 显示名称。
- 用户名/登录名：默认只读；若系统允许修改，必须进入单独验证流程。
- 主邮箱：显示验证状态 Chip。
- 个人简介。
- 语言、时区摘要。
- 账号创建时间、最近登录时间只读。

头像交互：
- 点击头像区域打开 `上传头像` Dialog。
- 支持拖拽/文件选择、裁剪预览、删除自定义头像。
- 展示文件类型与大小限制。
- 上传失败保留原头像，不先清空现有值。

### 编辑资料

字段按后端允许的 Profile Schema 展示。保存采用普通表单规则。

邮箱变更：
- 不直接作为普通文本字段覆盖。
- `更换邮箱` 打开独立流程。
- 输入新邮箱 → 发送验证 → 输入 OTP → 确认变更。
- 高风险部署策略可以要求 Step-up Verification。
- 修改完成前旧邮箱仍显示为当前有效邮箱。

## 3. 偏好设置总览

**路由：** `/console/account/preferences`

桌面端使用左侧设置分类 + 右侧内容；移动端使用设置列表进入二级页面。

分类：
- 外观。
- 语言与地区。
- Console 行为。
- 表格与列表。
- 快捷键。
- 隐私与本地状态。

每个设置行由：标题、解释、当前值、控件组成。需要服务器同步的偏好展示 `保存中…/已保存` 状态；只在当前设备生效的偏好明确标记 `仅此设备`。

## 4. 外观

### 4.1 主题

Segmented Button：
- 跟随系统。
- 浅色。
- 深色。

切换实时预览并立即应用。若服务器偏好保存失败，当前页面可临时保留并提示 `仅在本设备临时生效`，或按产品策略回滚；行为必须统一。

### 4.2 界面密度

选项：
- 舒适。
- 标准。
- 紧凑。

影响 Data Table、列表行间距、部分表单密度，但不得缩小低于全局最小点击区域。

### 4.3 导航形态

桌面端可选：
- 自动。
- 展开 Drawer。
- 紧凑 Rail。

窗口宽度不足时系统可覆盖为响应式形态；设置页显示 `在较窄窗口中会自动切换`。

## 5. 语言与地区

### 5.1 界面语言

Select 展示当前已安装语言。切换后：
- Console 文案立即切换。
- 当前页面路由、筛选、草稿不丢失。
- 后端返回的 canonical enum 不直接作为用户文案展示，应通过 i18n 映射。

### 5.2 时区

可搜索 Select：
- 默认 `跟随浏览器`。
- 也允许选择明确 IANA Time Zone，例如 `Asia/Shanghai`。

所有依赖时区的日历、任务、报表、定时计划页面显示实际采用的时区。修改时区后不改变后端已经保存的绝对时间，只改变显示与未来本地时间输入解释。

### 5.3 日期、时间和数字格式

设置：
- 日期格式：系统/语言默认、`YYYY-MM-DD` 等后端支持格式。
- 时间格式：24 小时 / 12 小时。
- 每周起始日。
- 数字/千分位格式跟随 Locale，若允许覆盖则明确展示示例。

页面右侧提供实时示例：
- `2026-08-31`
- `23:45`
- `12,345.67`

## 6. Console 行为

### 6.1 默认首页

Select 只列出当前用户有查看权限的顶级页面。

默认：`工作台 / 概览`。

用户丢失所选页面权限后，登录时自动回退到 Dashboard，并在偏好页标记原设置已失效。

### 6.2 页面状态恢复

Switch：
- `记住上次列表筛选`。
- `记住菜单展开状态`。
- `记住每个页面的视图模式`。

说明：
- URL 本身已经表达的筛选以 URL 为准。
- Secure Domain 的私密筛选不进入普通本地历史。

### 6.3 打开链接方式

设置：
- 详情默认当前标签页打开。
- 外部链接默认新标签页打开。

不得劫持用户 Ctrl/Cmd-click 等浏览器标准新标签行为。

### 6.4 后台任务行为

设置：
- 任务完成 Snackbar。
- 任务失败强提醒。
- 是否在页面右上角显示后台任务计数。

这些只是显示偏好，不改变后台任务实际执行或通知投递策略。

## 7. 表格与列表

### 7.1 默认分页大小

Select：`20 / 50 / 100`，具体上限按后端能力。

页面自己规定固定分页大小时，该页面规则优先。

### 7.2 默认列表密度

可继承全局界面密度或独立设置 `表格使用紧凑模式`。

### 7.3 列显示与恢复

偏好页提供：
- `管理已自定义表格` 列表。
- 每项显示页面名称、隐藏列数、最后修改时间。
- `恢复默认列`。

页面内列自定义仍在对应表格工具栏完成；此处提供统一清理入口。

### 7.4 排序/筛选持久化

- 默认不把一次临时排序永久变成用户偏好，除非用户选择 `设为默认`。
- `清除全部已保存列表状态` 使用确认 Dialog，明确不会删除业务数据。

## 8. 快捷键

**路由区域：** 偏好设置中的 `快捷键`。

### 快捷键表

列：
- 功能。
- 当前快捷键。
- 作用范围。
- 是否可修改。
- 重置。

基础快捷键建议：
- `Ctrl/Cmd + K`：全局搜索。
- `Ctrl/Cmd + S`：当前编辑器保存。
- `?`：打开快捷键帮助，仅在非文本输入状态触发。

自定义规则：
- 捕获新组合时显示键位可视化。
- 与浏览器/系统关键快捷键冲突时警告。
- 同一作用范围内重复绑定阻止保存或要求交换。
- 提供 `恢复默认快捷键`。

## 9. 通知偏好

**路由：** `/console/account/notifications`

这是当前用户自己的投递偏好，不等同于管理员的系统级 `沟通与审计 / 通知投递规则`。

### 页面区域

#### 通知类别

每行：
- 类别名称。
- 说明。
- In-app Switch。
- Email / 其他已配置个人渠道 Switch。
- 优先级说明。

类别示例：后台任务、同步、分享、计划提醒、安全通知、公告。

安全关键通知若后端策略强制不可关闭，Switch Disabled，并显示 `由安全策略强制启用`。

#### Quiet Hours

字段：
- 启用免打扰。
- 开始时间。
- 结束时间。
- 时区。
- 允许高优先级安全通知穿透。

跨午夜区间必须正确表示，例如 `22:00–07:00`。

#### Digest

支持时可设置每日/每周摘要时间。关闭某类即时通知不等于自动加入摘要，两个选项独立表达。

## 10. 个人安全与认证入口

**路由：** `/console/account/security`

本页只管理当前用户自己的安全状态。登录认证基于无状态 JWT，服务端不存在可枚举的 Login Session / Security Session，因此本页不展示活跃 Session、Session ID、单设备撤销或“退出其他 Session”列表。

卡片：
- 密码状态与 `修改密码`。
- 邮箱验证状态。
- 当前 JWT 有效期 / 是否需要重新认证。
- 当前 SVL / 最近 Step-up 状态的安全摘要。
- MFA/OTP 配置状态。
- 已授权 Trusted Device 数量（若未来支持；Trusted Device 是独立安全对象，不等于登录 Session）。
- 恢复准备状态。
- `使所有设备重新登录` 高风险操作。

### 修改密码

Dialog/独立页面字段：
- 当前密码或 Step-up Verification。
- 新密码。
- 确认新密码。

确认前说明安全策略是否会同步提升用户 `security_version`，从而使此前签发的全部 JWT 失效。

### 当前浏览器退出

退出当前浏览器：
- 清除本地 Access / Refresh JWT 与认证缓存；
- Lock 当前浏览器中的 Secure Domain；
- 清理解密 Key Material；
- 返回登录页。

普通退出不发送“撤销当前 Session”命令。

### 使所有设备重新登录

用户怀疑 Token 泄露、修改关键安全设置或需要强制重新认证时，执行：

```text
identity.invalidate-user-tokens
```

服务端提升目标用户：

```text
security_version
```

所有携带旧版本的 JWT 在后续请求中被拒绝。

该操作必须 Step-up Verification；执行成功后当前浏览器自己的旧 Token 也会失效，前端清理本地凭据并回到登录页。

## 11. 隐私与本地状态

设置项：
- 搜索历史：启用/关闭、清除。
- 最近使用创建项：清除。
- 本设备菜单/表格布局状态：清除。
- 剪贴板自动清理偏好，仅在平台能力支持时展示。

`清除本地 UI 状态` 不得误导为删除服务器业务数据。

绝不保存为普通偏好：
- Access Token / Refresh Token。
- Step-up Verification Grant。
- 密码、OTP、API Secret。
- 解密后的私密笔记/密码库内容。
- Root Key、KEK、恢复密钥。

## 12. 保存与冲突

- 普通简单偏好可以单项即时保存。
- 多字段设置（地区格式、通知 Quiet Hours）使用显式 `保存`。
- 多设备同时修改偏好发生版本冲突时，采用根规范的并发冲突规则；偏好可提供 `使用此设备设置覆盖`，但必须基于最新服务端版本提交。
- 服务端拒绝某设置时展示策略原因，例如 `管理员已强制 24 小时时间格式`；受策略锁定的控件显示锁图标和来源。

## 13. 无权限、降级与异常状态

- 当前用户始终可以访问基础个人资料和退出登录能力，除非账号本身已被禁用/撤销。
- 某功能由部署关闭时不显示空的设置分类。
- 偏好服务暂时不可用时，已加载设置保持可读；修改操作禁用并显示 `暂时无法保存设置`。
- 本地主题/语言可以在服务端不可达时临时工作，但恢复连接后不得静默覆盖服务器较新的设置；需要按版本策略同步。
